# Fantasy členy – der die das

GitHub Pages-ready PWA aplikace pro naši metodu:
- ⚔️ Viking = DER
- 🧙‍♀️ Čarodějka = DIE
- 👻 Strašidlo = DAS

Obsahuje všechna slovíčka z dosavadní kroniky, učení, test, náhodné pořadí, chytré opakování, kroniku a pokrok.

## GitHub Pages
1. Nahraj všechny soubory do kořenové složky repository.
2. GitHub → Settings → Pages.
3. Deploy from a branch → `main` → `/(root)` → Save.
4. Otevři vygenerovanou HTTPS adresu v Safari.
5. Na iPhonu: Sdílet → Přidat na plochu.

`index.html` musí být přímo v kořenu repository.
